# Google Sheets 標題顯示功能

## 📋 功能說明

當使用者在「Google Sheets 網址」欄位輸入或貼上連結後，系統會自動抓取並顯示該 Google Sheets 的標題。

## ✨ 功能特點

### 1. 自動偵測
- 當輸入欄位失去焦點（blur）時自動觸發
- 頁面載入時自動獲取預設網址的標題

### 2. 視覺效果
- 📊 圖示 + 工作表標題
- 漸層背景（藍色到紫色）
- 淡入動畫效果
- 載入中提示

### 3. 錯誤處理
- 無效網址：顯示 "⚠️ 無法取得標題"
- 網路錯誤：顯示錯誤訊息
- 空白網址：不顯示任何內容

## 🎯 使用方式

### 方法 1: 貼上連結後離開欄位
1. 在「Google Sheets 網址」欄位貼上連結
2. 點擊其他地方或按 Tab 鍵
3. 系統自動顯示工作表標題

### 方法 2: 頁面載入時自動顯示
1. 如果有預設網址，頁面載入時自動顯示標題

## 🔧 技術實作

### API 端點
使用 Google Sheets 的公開 JSON API：
```
https://docs.google.com/spreadsheets/d/{SPREADSHEET_ID}/gviz/tq?tqx=out:json&gid={GID}
```

### 資料結構
API 回應中的 `table.label` 欄位包含工作表標題。

### 新增的函數

#### googleSheets.js
```javascript
export const getSheetTitle = async (spreadsheetUrl) => {
  // 提取 spreadsheet ID 和 GID
  // 呼叫 API

}
```

## 🎨 UI 設計

### 樣式
- **背景**: 線性漸層 (#e3f2fd → #f3e5f5)
- **邊框**: 2px 紫色 (#b39ddb)
- **文字顏色**: 深紫色 (#5e35b1)
- **字重**: 600 (半粗體)
- **動畫**: 淡入 + 向下滑動

### 響應式
- 自動適應容器寬度
- 文字自動換行
- 手機版保持可讀性

## ⚠️ 注意事項

1. **權限要求**: Google Sheets 必須設定為「知道連結的人都能查看」
2. **網路延遲**: 首次載入可能需要 1-2 秒
3. **CORS**: 使用 Google Sheets 公開 API，無 CORS 問題
4. **快取**: 每次輸入/離開欄位都會重新抓取
